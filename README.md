# ARCADE GANG

오갱 현장 미니카 대회 운영용 정적 웹앱입니다.

## 이용 순서

1. 메인에서 대회 이름·날짜·종목을 입력합니다.
2. 선수 이름을 한 명씩 접수하거나 명단을 한 번에 추가합니다. `셀프 접수 화면`은 현장 태블릿을 선수에게 건네 직접 입력받는 모드입니다.
3. 대진표를 추첨하고 이름과 레인을 확인합니다.
4. 출력 화면을 열거나 경기 진행 화면으로 이동합니다.
5. 경기할 조를 누르면 소개가 시작되고, 선수 이름을 누르면 승자가 확정됩니다. 다음 라운드는 휴식 후 시작 버튼을 눌러 진행합니다.

## 편성

- 3~64명, 토너먼트 3라운드, 라운드별 1명 진출 후 최종 3인 결승.
- 최초 편성은 3인조·2인조이며, 세 라운드 동안 각 선수에게 1·2·3레인을 한 번씩 배정합니다.
- 이미 진출한 선수는 후속 라운드에서 빠집니다. 남은 선수의 출력물 레인 자리는 유지합니다.
- 24명까지는 3개 라운드를 A4 세로 한 장에 출력합니다. 인원이 더 많으면 라운드마다 한 장을 사용합니다.
- 최초 편성 이후 한 명만 남은 조는 자동으로 승자를 확정하지 않고 운영자가 선택합니다.

## 저장 범위

로그인과 서버 DB를 사용하지 않습니다. 대회·접수 명단·경기 기록은 현재 기기의 브라우저에 저장됩니다. 다른 기기에서 같은 주소를 열어도 명단이 자동으로 공유되지 않습니다. 운영자 창과 관중용 창은 같은 브라우저에서 연동됩니다. 대회별 백업 버튼으로 JSON을 저장할 수 있습니다. 새 대회를 만들어도 기존 대회는 보존됩니다.

## 배포

Cloudflare Pages와 GitHub의 `main` 브랜치 연결을 사용합니다. Framework preset은 `None`, Build command는 `exit 0`, Build output directory는 `/`입니다. 별도 설치나 빌드는 없습니다. `index.html`이 메인, `live.html`이 경기 진행, `print.html`이 출력 화면입니다.

기능 확인은 HTTP(S)의 같은 주소에서 진행하세요. 로컬 `file://`로 파일을 개별 실행하는 경우 브라우저마다 저장소 공유 방식이 달라질 수 있습니다.

## 카메라 랩타이머 (1차 구현)

`camera.html`은 휴대폰 단독 카메라 계측 화면입니다. 메인 상단과 경기 운영 화면에서 열 수 있습니다. 아직 노트북 전송, 접수 선수 자동 연결, 공식 승자 자동 확정 기능은 붙이지 않았습니다.

1. 배포된 HTTPS 주소를 휴대폰 Chrome/Safari에서 엽니다.
2. 카메라 권한을 허용하고 휴대폰을 고정합니다. 감지창 3개를 실제 레인에 맞춰 드래그합니다.
3. 측정할 차량의 출발 레인, 목표 바퀴 수, 레인 이동 방향을 설정합니다. 한 대 시험부터 시작하는 것을 권장합니다.
4. 트랙을 비우고 자동 계측 시작을 누릅니다. 배경 학습 후 첫 통과를 0점으로 잡고, 이후 목표 바퀴 수만큼의 통과 간격을 측정합니다.
5. 완주 기록은 기기에 자동 저장됩니다. 중단 기록은 구분해서 저장하며 JSON/CSV로 내려받을 수 있습니다. 영상은 저장·전송하지 않습니다.

카메라가 없어도 `가상 차량으로 동작 체험`에서 같은 프레임 감지 로직을 거쳐 테스트할 수 있습니다. 이 기록은 SIMULATION으로 표시됩니다.

레인체인지 추적에서 후보가 여럿이면 임의로 배정하지 않고 확인 필요로 중단합니다. 최초 차량 통과는 첫 통과 후 최대 0.9초(또는 최소 랩 간격의 70%) 안에 감지되어야 합니다. 그 뒤 출발 미감지 차량은 미측정으로 표시됩니다. 처음부터 출발 신호의 절대 경기 시간을 측정하는 방식은 아닙니다.

실제 FPS와 프레임 간격을 표시하되, 프레임 콜백 누락·조명·셔터·거치 위치에 따라 감지 누락과 시간 오차가 생길 수 있습니다. 실제 트랙과 기준 계측기로 정확도를 검증하기 전 공식 경기 판정에 사용하지 마세요. 화면 잠금·탭 이탈·카메라 해제 시 계측을 중단하고 부분 기록을 보존합니다.
